# Portfolio V1 design (historical)

Superseded by [the V2 design](design-v2.md).

A lightweight Next.js App Router portfolio for recruiters evaluating Tam’s data and ML engineering work. Warm white, dark ink, one teal accent, generous spacing, and system diagrams establish a coherent engineering identity. Arial/Helvetica system typography avoids runtime font requests. Server components render content; only navigation and filtering need client state. CSS provides restrained motion and respects reduced-motion preferences.

Structured TypeScript data separates supplied facts from presentation. Missing contacts are empty configuration values; missing resume files render a useful fallback. Unknown benchmark conditions are disclosed. No undocumented experiment results or infrastructure are invented. All primary routes, per-project case studies, metadata, sitemap, robots and an Open Graph image are included.

A database or CMS adds no value for this content size. Dark mode and animation libraries are omitted to keep the initial system focused and lightweight.
